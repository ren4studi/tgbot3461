# Бот для приёма заявок на покупку товаров

## Возможности
- Меню после /start: 
  - 1 — Вызов техподдержки
  - 2 — Оформить заказ (отправляет заявку в группу)
- Поддержка состояний: бот просит ввести текст обращения/заказа и отправляет в группу.

## Быстрый старт
1. Установите Python 3.10+
2. Скопируйте `.env.example` в `.env` и заполните значения:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `ORDERS_CHAT_ID` — ID группы, куда будут приходить заявки (бот должен быть добавлен в эту группу и иметь право писать)
   - `SUPPORT_CHAT_ID` — (необязательно) ID группы техподдержки
3. Установка зависимостей:
```bash
pip install -r requirements.txt
```
4. Запуск бота (polling):
```bash
python bot.py
```

## Как узнать ID группы
- Добавьте бота в группу и сделайте его администратором (минимум право писать).
- Включите в группе «Историю чата для новых участников».
- Самый простой способ: используйте бота-помощника (например, @getidsbot) или пересланное сообщение в ваш бот и считайте `chat.id` из логов.

## Использование
- Пользователь пишет `/start` — получает меню с двумя кнопками.
- «Вызов техподдержки» — бот попросит описать проблему. Если задан `SUPPORT_CHAT_ID`, сообщение уйдёт в группу поддержки, иначе останется в приватном диалоге.
- «Оформить заказ» — бот попросит ввести детали заказа (товар, количество, контакты). Сообщение уйдёт в группу `ORDERS_CHAT_ID`.
