# 🤖 Telegram Бот для приема заявок на покупку товаров

Этот бот предназначен для приема заявок на покупку товаров от пользователей. Бот имеет интуитивно понятный интерфейс с меню и автоматически отправляет заказы в указанную группу.

## ✨ Функциональность

- 🏠 **Главное меню** с двумя основными пунктами
- 🆘 **Техническая поддержка** - информация для связи с поддержкой
- 🛒 **Оформление заказа** - пошаговый процесс сбора информации
- 📤 **Автоматическая отправка заказов** в группу для менеджеров
- 🔄 **Удобная навигация** с кнопками возврата в меню

## 🚀 Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Создание бота в Telegram

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен

### 3. Настройка группы для заказов

1. Создайте группу в Telegram
2. Добавьте вашего бота в группу как администратора
3. Отправьте любое сообщение в группу
4. Получите ID группы через API или специальные боты

### 4. Настройка переменных окружения

1. Скопируйте файл `.env.example` в `.env`
2. Заполните переменные:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
GROUP_ID=-1001234567890
```

## 🏃‍♂️ Запуск бота

```bash
python bot.py
```

## 📱 Как использовать

### Для пользователей:

1. **Запуск бота**: Отправьте команду `/start`
2. **Главное меню**: Выберите нужный пункт из меню
3. **Тех. поддержка**: Получите контактную информацию
4. **Оформление заказа**: Пройдите пошаговый процесс:
   - Введите имя
   - Введите номер телефона
   - Введите адрес доставки
   - Опишите товары для заказа

### Для администраторов:

- Все заказы автоматически приходят в указанную группу
- Каждый заказ содержит полную информацию о клиенте
- Время заказа и ID пользователя автоматически добавляются
