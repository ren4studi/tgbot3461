## Бот для приёма заявок на покупку товаров

Функциональность:
- /start показывает инструкцию и меню
- Пункты меню: 1) вызов техподдержки 2) оформить заказ
- Заявки на заказ отправляются в указанную группу Telegram
- (Опционально) обращения в техподдержку также можно пересылать в группу

### Быстрый старт
1) Создайте бота через BotFather и получите токен
2) Создайте/узнайте chat id группы, куда слать заявки (пример: `-1001234567890`)
3) Добавьте бота в эту группу (он должен быть участником, чтобы писать в неё)
4) Скопируйте `.env.example` в `.env` и заполните значения

```bash
cp .env.example .env
# затем отредактируйте .env
```

Переменные окружения:
- `TELEGRAM_BOT_TOKEN` — токен бота
- `ORDERS_GROUP_ID` — chat id группы для заявок на покупку
- `SUPPORT_GROUP_ID` — необязательный chat id группы для техподдержки

Как узнать chat id группы: добавьте бота в группу, отправьте любое сообщение в неё и воспользуйтесь ботом `@RawDataBot` или любым аналогом; либо временно включите логирование обновлений в своём коде.

### Установка и запуск
```bash
python -m venv .venv && source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m bot.main
```

### Использование
- В личном чате с ботом отправьте `/start`
- Выберите пункт меню:
  - «Оформить заказ»: опишите заказ одним сообщением; бот перешлёт его в группу
  - «Вызов техподдержки»: опишите проблему; при наличии `SUPPORT_GROUP_ID` бот отправит обращение в группу

### Примечание
- Если бот не может писать в группу, убедитесь, что он добавлен в неё (и при необходимости имеет право отправлять сообщения).
