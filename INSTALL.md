# 📥 Установка и настройка Telegram бота заказов

## 🎯 Обзор установки

Этот документ содержит пошаговые инструкции по установке и настройке Telegram бота для приема заказов на всех поддерживаемых платформах.

## 📋 Системные требования

### Минимальные требования
- **Операционная система**: Windows 10+, macOS 10.14+, Ubuntu 18.04+
- **Python**: версия 3.7 или выше
- **RAM**: 512 MB
- **Дисковое пространство**: 100 MB
- **Интернет**: стабильное подключение

### Рекомендуемые требования
- **Операционная система**: Windows 11+, macOS 12+, Ubuntu 20.04+
- **Python**: версия 3.9 или выше
- **RAM**: 1 GB
- **Дисковое пространство**: 500 MB
- **Интернет**: высокоскоростное подключение

## 🚀 Быстрая установка

### Шаг 1: Скачивание проекта
```bash
# Клонирование из Git
git clone https://github.com/yourusername/telegram-order-bot.git
cd telegram-order-bot

# Или скачивание ZIP архива
wget https://github.com/yourusername/telegram-order-bot/archive/main.zip
unzip main.zip
cd telegram-order-bot-main
```

### Шаг 2: Установка Python
#### Windows
1. Скачайте Python с [python.org](https://python.org)
2. Запустите установщик
3. **Обязательно** поставьте галочку "Add Python to PATH"
4. Завершите установку

#### macOS
```bash
# Через Homebrew
brew install python3

# Или скачайте с python.org
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv -y
```

#### Linux (CentOS/RHEL)
```bash
sudo yum install python3 python3-pip -y
```

### Шаг 3: Проверка Python
```bash
python3 --version
# Должно показать Python 3.7 или выше

pip3 --version
# Должно показать версию pip
```

### Шаг 4: Создание виртуального окружения
```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (macOS/Linux)
source venv/bin/activate
```

### Шаг 5: Установка зависимостей
```bash
# Обновление pip
pip install --upgrade pip

# Установка зависимостей
pip install -r requirements.txt
```

## ⚙️ Настройка бота

### Шаг 1: Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Введите имя для бота (например: "Магазин заказов")
4. Введите username (например: `my_shop_bot`)
5. **Сохраните токен** - он понадобится для настройки

### Шаг 2: Создание группы для заказов
1. Создайте новую группу в Telegram
2. Добавьте вашего бота в группу как администратора
3. Отправьте любое сообщение в группу
4. Получите ID группы через API

### Шаг 3: Получение ID группы
```bash
# Запустите скрипт для получения ID
python get_group_id.py

# Или используйте API напрямую
curl "https://api.telegram.org/botВАШ_ТОКЕН/getUpdates"
```

### Шаг 4: Настройка переменных окружения
```bash
# Копирование примера
cp .env.example .env

# Редактирование файла
nano .env  # Linux/macOS
notepad .env  # Windows
```

Содержимое `.env`:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
GROUP_ID=-1001234567890
```

## 🚀 Запуск в продакшене

### Linux/macOS
```bash
# Сделайте скрипты исполняемыми
chmod +x start_bot.sh stop_bot.sh

# Запуск в фоновом режиме
./start_bot.sh

# Проверка статуса
ps aux | grep bot.py

# Остановка
./stop_bot.sh
```

### Windows
```batch
# Создайте start_bot.bat
@echo off
cd /d "C:\путь\к\вашему\боту"
call venv\Scripts\activate
python bot.py
pause
```

### Автозапуск через systemd (Linux)
```bash
# Создание сервиса
sudo nano /etc/systemd/system/telegram-bot.service
```

Содержимое:
```ini
[Unit]
Description=Telegram Order Bot
After=network.target

[Service]
Type=simple
User=your_username
WorkingDirectory=/path/to/your/bot
Environment=PATH=/path/to/your/bot/venv/bin
ExecStart=/path/to/your/bot/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# Активация сервиса
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
sudo systemctl status telegram-bot
```

## 🚨 Устранение неполадок

### Проблема: "Python не найден"
**Решение**:
```bash
# Windows: добавьте Python в PATH
# macOS/Linux: используйте python3
python3 --version
```

### Проблема: "pip не найден"
**Решение**:
```bash
# Установка pip
curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
python3 get-pip.py
```

### Проблема: "Ошибка импорта модулей"
**Решение**:
```bash
# Активируйте виртуальное окружение
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate      # Windows

# Переустановите зависимости
pip install --force-reinstall -r requirements.txt
```

### Проблема: "Ошибка прав доступа"
**Решение**:
```bash
# Linux/macOS: измените права
chmod +x *.sh
chmod 755 venv/

# Windows: запустите от имени администратора
```

### Проблема: "Бот не подключается к API"
**Решение**:
1. Проверьте токен в `.env`
2. Убедитесь в доступе к интернету
3. Проверьте, что бот не заблокирован
4. Попробуйте другой токен
