# 📋 Краткий обзор проекта Telegram бота заказов

## 🎯 Что это такое?

Полнофункциональный Telegram бот для автоматизации приема заказов от клиентов. Бот принимает команду `/start`, показывает меню с двумя пунктами (тех. поддержка и оформление заказа), пошагово собирает информацию и автоматически отправляет заказы в указанную группу.

## 🚀 Основные функции

- ✅ **Команда /start** - запуск бота и главное меню
- ✅ **Техническая поддержка** - информация для связи с поддержкой
- ✅ **Оформление заказа** - пошаговый процесс сбора информации
- ✅ **Автоматическая отправка** - заказы приходят в группу для менеджеров
- ✅ **Удобная навигация** - кнопки для перемещения между разделами

## 📱 Как работает

### 1. Пользователь отправляет `/start`
Бот отвечает приветствием и показывает главное меню с двумя кнопками.

### 2. Главное меню
- **1️⃣ Вызов тех. поддержки** - информация о поддержке
- **2️⃣ Оформить заказ** - начало процесса заказа

### 3. Процесс заказа (4 шага)
1. **Имя клиента**
2. **Номер телефона**
3. **Адрес доставки**
4. **Список товаров**

### 4. Автоматическая отправка
После завершения заказа, вся информация автоматически отправляется в указанную группу.

## 🛠️ Установка

### Быстрая установка (5 минут)
1. Создайте бота в @BotFather
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте `.env` файл
4. Запустите: `python bot.py`

### Подробная установка
См. файлы `INSTALL.md` и `SETUP.md` для полных инструкций.
