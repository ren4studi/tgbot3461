## 📋 Быстрая настройка

### 1️⃣ Создайте бота в Telegram
1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Введите имя (например: "Магазин заказов")
4. Введите username (например: `my_shop_bot`)
5. **Сохраните токен!** (например: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2️⃣ Создайте группу для заказов
1. Создайте новую группу в Telegram
2. Добавьте вашего бота в группу
3. Отправьте любое сообщение в группу
4. Получите ID группы через: `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`

### 3️⃣ Настройте файлы
```bash
# Скопируйте .env.example в .env
cp .env.example .env

# Отредактируйте .env
nano .env
```

Содержимое `.env`:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
GROUP_ID=-1001234567890
```

### 4️⃣ Установите зависимости
```bash
pip install -r requirements.txt
```

### 5️⃣ Запустите бота
```bash
python bot.py
```

## 🔧 Если что-то не работает

### Проблема: "Бот не отвечает"
```bash
# Проверьте, что бот запущен
ps aux | grep bot.py

# Проверьте логи
tail -f logs/bot.log
```

### Проблема: "Заказы не приходят в группу"
- ✅ Проверьте ID группы в `.env`
- ✅ Убедитесь, что бот добавлен в группу
- ✅ Проверьте права бота в группе

### Проблема: "Ошибка импорта"
```bash
# Переустановите зависимости
pip install --force-reinstall -r requirements.txt
```
