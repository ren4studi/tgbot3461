# 🤖 Telegram Бот для приема заявок на покупку товаров

[![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)](https://python.org)
[![Telegram Bot API](https://img.shields.io/badge/Telegram%20Bot%20API-6.0+-green.svg)](https://core.telegram.org/bots/api)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Полнофункциональный Telegram бот для автоматизации приема заказов от клиентов. Бот имеет интуитивно понятный интерфейс, пошаговый процесс оформления заказов и автоматическую отправку заявок в указанную группу для менеджеров.

## ✨ Основные возможности

- 🏠 **Главное меню** с двумя основными пунктами
- 🆘 **Техническая поддержка** - информация для связи с поддержкой
- 🛒 **Оформление заказа** - пошаговый процесс сбора информации
- 📤 **Автоматическая отправка заказов** в группу для менеджеров
- 🔄 **Удобная навигация** с кнопками возврата в меню
- 📱 **Адаптивный интерфейс** для всех устройств
- 🔒 **Безопасность** с валидацией данных и логированием

## 🚀 Быстрый старт

### 1. Создайте бота в Telegram
- Найдите [@BotFather](https://t.me/BotFather) в Telegram
- Отправьте команду `/newbot`
- Следуйте инструкциям и сохраните токен

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте переменные окружения
```bash
cp .env.example .env
# Отредактируйте .env файл с вашими данными
```

### 4. Запустите бота
```bash
python bot.py
```

**Полные инструкции**: [QUICK_START.md](QUICK_START.md) | [SETUP.md](SETUP.md)

## 📱 Как работает бот

### 1. Запуск
Пользователь отправляет команду `/start` и получает приветствие с главным меню.

### 2. Главное меню
Два основных пункта:
- **1️⃣ Вызов тех. поддержки** - информация для связи
- **2️⃣ Оформить заказ** - начало процесса заказа

### 3. Оформление заказа
Пошаговый процесс сбора информации:
1. **Имя клиента**
2. **Номер телефона**
3. **Адрес доставки**
4. **Список товаров**

### 4. Автоматическая отправка
После завершения заказа, вся информация автоматически отправляется в указанную группу для обработки менеджерами.
