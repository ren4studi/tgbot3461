# 📚 Полное руководство по Telegram боту заказов

## 🎯 Обзор проекта

Этот проект представляет собой **полнофункциональный Telegram бот для автоматизации приема заказов от клиентов**. Бот разработан с учетом современных требований к пользовательскому интерфейсу, безопасности и масштабируемости.

## 🚀 Что вы получите

После настройки у вас будет бот, который:

### ✅ Основные функции
- **Принимает команду `/start`** и показывает приветствие
- **Отображает главное меню** с двумя основными пунктами
- **Предоставляет техническую поддержку** с контактной информацией
- **Оформляет заказы** пошагово, собирая всю необходимую информацию
- **Автоматически отправляет заказы** в указанную группу для менеджеров
- **Имеет удобную навигацию** с кнопками возврата в меню

### ✅ Технические возможности
- **Асинхронная обработка** сообщений
- **Валидация входных данных** для безопасности
- **Логирование всех действий** для мониторинга
- **Обработка ошибок** с понятными сообщениями
- **Модульная архитектура** для легкого расширения

## 🛠️ Установка и настройка

### Быстрая установка (5 минут)

#### Шаг 1: Создание бота в Telegram
1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Введите имя для бота (например: "Магазин заказов")
4. Введите username (например: `my_shop_bot`)
5. **Сохраните токен** - он понадобится для настройки

#### Шаг 2: Создание группы для заказов
1. Создайте новую группу в Telegram
2. Добавьте вашего бота в группу как администратора
3. Отправьте любое сообщение в группу
4. Получите ID группы через API

#### Шаг 3: Настройка файлов
```bash
# Скопируйте .env.example в .env
cp .env.example .env

# Отредактируйте .env
nano .env
```

Содержимое `.env`:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
GROUP_ID=-1001234567890
```

#### Шаг 4: Установка зависимостей
```bash
pip install -r requirements.txt
```

#### Шаг 5: Запуск бота
```bash
python bot.py
```

## 🚨 Устранение неполадок

### Частые проблемы

#### 1. Бот не отвечает
**Симптомы**: Бот не реагирует на команды
**Решение**:
1. Проверьте, что бот запущен (`python bot.py`)
2. Проверьте токен в `.env`
3. Проверьте интернет-соединение
4. Проверьте логи на ошибки

#### 2. Заказы не приходят в группу
**Симптомы**: Заказы оформляются, но не появляются в группе
**Решение**:
1. Проверьте ID группы в `.env`
2. Убедитесь, что бот добавлен в группу
3. Проверьте права бота в группе
4. Проверьте логи на ошибки отправки

#### 3. Ошибки импорта модулей
**Симптомы**: Ошибки при запуске типа "ModuleNotFoundError"
**Решение**:
1. Установите зависимости: `pip install -r requirements.txt`
2. Проверьте версию Python (должна быть 3.7+)
3. Активируйте виртуальное окружение

#### 4. Файл .env не найден
**Симптомы**: Ошибка "BOT_TOKEN не найден в переменных окружения"
**Решение**:
1. Создайте файл `.env` на основе `.env.example`
2. Убедитесь, что файл в той же папке, что и `bot.py`
3. Проверьте права доступа к файлу
